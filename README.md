# HR-аналитика: анализ текучести персонала

## О проекте
Проект посвящён анализу причин увольнения сотрудников на основе открытого датасета **IBM HR Analytics**.  
Цель — выявить ключевые факторы текучки и предложить бизнес-рекомендации для снижения оттока персонала.

## Инструменты
- Microsoft Excel (сводные таблицы, условное форматирование, ML-срезы)

## Структура отчёта
| Лист | Содержание |
|------|------------|
| `README` | Описание проекта |
| `Raw Data` | Исходные данные (1470 записей, 35 полей) |
| `Cleaned Data` | Очищенные и подготовленные данные |
| `Pivot Tables` | 6 блоков анализа по ключевым факторам |
| `Dashboard` | Ключевые выводы и рекомендации |
| `ML срезы` | Многомерный анализ групп риска |

## Ключевые выводы
1. **Финансы** — низкая базовая ставка на грейде 1 (риск 21%), роли Laboratory Technician, Sales Representative, Human Resources
2. **Выгорание** — долгоработающие сотрудники (10–40 лет) с плохим балансом без переработок (риск до 50%)
3. **Карьерный рост** — пики увольнений на 2–3 и 14–15 годах стажа
4. **Адаптация** — 28% новичков уходят в первый год
5. **Среда** — частые командировки повышают риск в 3,1 раза

## Рекомендации
- Поднять зарплаты на грейде 1 до рыночного уровня
- Ввести «правило 3 лет» для повышения
- Минимум 2–3 тренинга в год на сотрудника
- Провести интервью с теми, кто давно работает (стаж 10+ лет)
